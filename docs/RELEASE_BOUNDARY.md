# DNCrypt release boundary

The research archive is cumulative and preserves private-development lineage under `lineage/` and `references/`.

A public distribution can be generated from the current source, protocol, tests and public documentation while omitting private-development bindings and cumulative internal lineage. Such packaging changes distribution provenance only; the DNCrypt v0.2 cryptographic protocol remains byte-defined by the frozen protocol document and source tree included in that release.
